给后台换成角色权限之后，普通运营能看到财务页，禁用角色还能照常登录：角色展开只走一层父角色，多级继承全部丢失；角色展开遇到环直接递归溢出，没有访问集合；资源匹配用前缀比较，前缀相同的资源被越权；资源通配符跨段匹配，多级路径被放行；拒绝规则只在允许集合为空时才生效，拒绝被忽略；判定不检查用户是否被禁用，禁用用户仍然放行；有效权限不过滤禁用角色；角色图校验不检查未知父角色，拼写错误被静默忽略；授权审计只记最终结果不记来源角色，无法追责；批量判定复用展开后的角色集合，后一个用户用前一个用户的权限。perm/rbac.py 是核心，tests/test_rbac.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

## 运行方式

在仓库根目录执行：

    python -m pytest tests -q

初始状态必须恰好是 15 failed，不能出现 collection error、import error 或 syntax error；修复 rbac.py 后应为 15 passed。
